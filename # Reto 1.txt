### Requerimientos (funcionales y no funcionales)

**Funcionales (alineados al reto):**

- Clasificar ticket (tipo + categoría)
- Priorizar (impacto/urgencia/contexto)
- Generar respuesta clara
- Detectar recurrencias + RCA tentativa
- Explicar decisiones (trazabilidad)

**No funcionales (muy importantes para enterprise):**

- Auditabilidad (guardar razón de decisiones)
- Seguridad (no exponer credenciales; sanitización de datos)
- Confiabilidad (fallback si LLM falla)
- Latencia objetivo (ej. <5–8s por ticket)
- Observabilidad (logs por agente)

**Salida**: checklist.

### 6) Flujo end-to-end (workflow del incidente)

1.  **Interacción Inicial (Chat):** El usuario describe el problema en lenguaje natural.

2. **Normalización + extracción de campos:** El agente verifica si falta información (ej. sistema afectado, descripcion del problema). Si es **ambiguo**, repregunta hasta completar los campos.

3. **Clasificación y Priorización:** El agente analizan el texto para determinar el **Tipo** (Incidente/Requerimiento) y el **Nivel** (1, 2 o 3) según el impacto.

4. **Acción en JIRA:** El agente llama a la API de Jira, crea el ticket y recibe la URL única.

5. **Persistencia en BD:** Se guardan los datos del ticket, la traza de la conversación y la decisión de la IA para futuras **auditorías**.

6. **Cierre del Ciclo:** El agente retorna el link de Jira al usuario para su seguimiento.

**Salida**: “Happy path” + “Edge cases”.

| **Escenario** | **Comportamiento del Agente** |
| --- | --- |
| **Happy Path** | El usuario da datos claros, la IA clasifica correctamente, crea el ticket en Jira y entrega el link en segundos. |
| **Edge Case: Ambigüedad** | El usuario dice "No funciona". El agente detecta que es ambiguo y solicita detalles del sistema antes de registrar. |
| **Edge Case: Crítico** | Se detecta "Servidor caído". El agente prioriza Nivel 3 automáticamente y omite preguntas secundarias para agilizar el reporte. |

## 2) Función para renderizarla (con defaults “bonitos”)

```
fromdatetimeimportdatetime
fromtypingimportAny,Dict,List

def_bullet_list(items:List[str],empty_text:str="-") ->str:
ifnotitems:
returnempty_text
return"\n".join([f"-{x}"forxinitems])

def_inline_list(items:List[str],empty_text:str="-") ->str:
ifnotitems:
returnempty_text
return", ".join(items)

defrender_incident_template_pro(
issue:Dict[str,Any],
enrichment:Dict[str,Any],
assistant_version:str="GenIA-ITSM v1"
) ->str:
now=datetime.now().isoformat(timespec="seconds")

# Inputs (desde Jira)
issue_key=issue.get("issue_key","-")
created_at=issue.get("created_at","-")
reporter_email=issue.get("reporter_email","-")
reporter_department=issue.get("reporter_department","-")
channel=issue.get("channel","Jira")
summary=issue.get("summary","-")
original_description=issue.get("description","-")

# Enrichment (desde agentes)
cls=enrichment.get("classification", {})
prio=enrichment.get("prioritization", {})
sup=enrichment.get("support", {})
ana=enrichment.get("analytics", {})
exp=enrichment.get("explainability", {})
orch=enrichment.get("orchestrator", {})

confidence=cls.get("confidence",None)
confidence_pct=f"{confidence*100:.0f}%"ifisinstance(confidence, (float,int))else"-"

filled=INCIDENT_TEMPLATE_PRO.format(
issue_key=issue_key,
created_at=created_at,
reporter_email=reporter_email,
reporter_department=reporter_department,
channel=channel,
summary=summary,
original_description=original_description,

ticket_type=cls.get("ticket_type","-"),
category=cls.get("category","-"),
sub_category=cls.get("sub_category","-"),
service=cls.get("service",issue.get("service","-")),
environment=cls.get("environment",issue.get("environment","-")),
assignment_group=cls.get("assignment_group","-"),
confidence_pct=confidence_pct,
missing_fields=_bullet_list(cls.get("missing_fields", [])),

impact=prio.get("impact","-"),
urgency=prio.get("urgency","-"),
priority=prio.get("priority","-"),

evidence_snippets=_inline_list(exp.get("evidence_snippets", [])),
assumptions=_inline_list(exp.get("assumptions", [])),
rules_used=_inline_list(exp.get("rules_used", [])),

user_reply_draft=sup.get("user_reply_draft","-"),
clarifying_questions=_bullet_list(sup.get("clarifying_questions", [])),

is_recurrent=str(ana.get("is_recurrent","-")),
similar_tickets=_inline_list(ana.get("similar_tickets", [])),
probable_cause=ana.get("probable_cause","-"),
preventive_action=ana.get("preventive_action","-"),

next_steps_internal=_bullet_list(orch.get("next_steps_internal", [])),
suggested_labels=_inline_list(orch.get("suggested_labels", [])),

assistant_version=assistant_version,
processed_at=now
    )
returnfilled
```

## 3) Publicarlo en Jira (comentario recomendado) + ADF

```
importrequests
fromrequests.authimportHTTPBasicAuth

defadf_from_plain_text(text:str) ->dict:
# Convierte texto con saltos de línea a ADF (párrafos).
paragraphs= []
forlineintext.splitlines():
paragraphs.append({
"type":"paragraph",
"content": [{"type":"text","text":lineiflineelse" "}]
        })
return {"type":"doc","version":1,"content":paragraphs}

classJiraClient:
def__init__(self,base_url:str,email:str,api_token:str):
self.base_url=base_url.rstrip("/")
self.auth=HTTPBasicAuth(email,api_token)
self.headers= {"Accept":"application/json","Content-Type":"application/json"}

defadd_comment(self,issue_key:str,comment_text:str) ->dict:
url=f"{self.base_url}/rest/api/3/issue/{issue_key}/comment"
payload= {"body":adf_from_plain_text(comment_text)}
r=requests.post(url,json=payload,headers=self.headers,auth=self.auth)
r.raise_for_status()
returnr.json()

defupdate_description(self,issue_key:str,description_text:str):
url=f"{self.base_url}/rest/api/3/issue/{issue_key}"
payload= {"fields": {"description":adf_from_plain_text(description_text)}}
r=requests.put(url,json=payload,headers=self.headers,auth=self.auth)
r.raise_for_status()
```

## 4) “Aplicar plantilla” en tu backend (la función que llamas y ya)

```
defapply_incident_template_pro(
jira:JiraClient,
issue:Dict[str,Any],
enrichment:Dict[str,Any],
mode:str="comment"# "comment" o "description"
):
"""
    mode="comment": agrega comentario con enriquecimiento (recomendado)
    mode="description": reemplaza description por el enriquecimiento (no recomendado en enterprise)
    """
text=render_incident_template_pro(issue,enrichment)

issue_key=issue["issue_key"]
ifmode=="comment":
jira.add_comment(issue_key,text)
elifmode=="description":
jira.update_description(issue_key,text)
else:
raiseValueError("mode debe ser 'comment' o 'description'")
```
